# Orrery Shaders

Orrery ships its own shader pack for Iris. The source lives in `shaderpack/` and is embedded into the launcher at build time, so there is no separate download or hosting.

## Features

- Deferred lighting: the geometry writes albedo, normals, light levels and a material id, and the `deferred` pass lights every pixel once
- Soft sun and moon shadows with a distorted shadow map and rotated Vogel disk filtering
- Screen space ambient occlusion, translucent leaves and plants, wet surfaces in rain, glowing blocks from `block.properties`
- Volumetric clouds raymarched through 3D noise with light marching, and light rays through the shadow map
- Sky with a day gradient, violet dusk, a star field that rotates with the sun path, a nebula band and an aurora. A galaxy sky in the End
- Water with refraction, depth based absorption, caustics, screen space reflections of the terrain, Fresnel sky reflection and a sun highlight
- Waving leaves and plants, also in the shadow map
- Temporal anti-aliasing with sub-pixel jitter, bloom from mipmaps, ACES tone mapping and a light Orrery color grade
- Distance, border and underwater fog, plus Nether and End handling through the Iris uniforms `hasSkylight` and `hasCeiling`
- Profiles Low, Medium, High and Ultra and an options menu in English and German. Medium runs on integrated graphics, High adds volumetric clouds and light rays

## Pipeline

| Pass             | Work                                                                                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shadow`         | Shadow map with distortion and waving foliage                                                                                                                  |
| `gbuffers_*`     | Opaque geometry writes `colortex0` albedo, `colortex1` normal and light, `colortex2` material. Hand and lit particles are shaded forward and marked as pre-lit |
| `deferred`       | Lighting, shadows, ambient occlusion and fog. Writes the lit scene and a copy in `colortex4`                                                                   |
| `gbuffers_water` | Forward water that reads `colortex4` and `depthtex1` for refraction and reflections                                                                            |
| `composite`      | Volumetric clouds and light rays                                                                                                                               |
| `composite1`     | Temporal anti-aliasing with history in `colortex5`                                                                                                             |
| `final`          | Sharpening, bloom, tone mapping and grading                                                                                                                    |

## Layout

| Path                         | Content                                                                                                                                   |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `shaders/*.vsh`, `*.fsh`     | Thin entry points. Each sets the stage and a mode and includes a program body.                                                            |
| `shaders/program/`           | Program bodies, one per pass type.                                                                                                        |
| `shaders/lib/`               | Shared code: settings, uniforms and helpers, sky, lighting, fog, shadows.                                                                 |
| `shaders/shaders.properties` | Profiles, option screens, sliders and Iris switches.                                                                                      |
| `shaders/block.properties`   | Block ids for water (10001), emissive blocks (10002), leaves (10003) and plants (10004).                                                  |
| `shaders/lang/`              | Option names in `en_us` and `de_de`. Both files must have the same keys.                                                                  |
| `shaders/textures/noise.png` | Generated by `cargo run --example noise_texture`: random values with a shifted copy for 3D noise, a tileable smooth noise and blue noise. |

Iris reads option values from `#define NAME value // [a b c]` and buffer formats from `/* const int colortex0Format = RGBA16F; */`. These look like comments but are required syntax. Boolean options are only recognized when the code checks them with `#ifdef` or `#ifndef`.

## How the launcher installs it

`orrery_core::shaderpack` builds a deterministic zip (fixed timestamps, sorted entries) from the embedded files and writes it to `shaderpacks/Orrery-Shaders-<version>.zip`. The entry in `mods.json` uses the project id `orrery-shaders`. Installing from the Shaders tab also installs Iris if it is missing, selects the pack in `config/iris.properties` and writes `shaderpacks/<zip>.txt` with the values of the profile that matches the hardware tier. An existing options file is never overwritten.

Updates are detected by comparing the stored SHA-512 with the embedded pack. An update replaces the old zip, carries the options file over and keeps the player's pack selection.

## Development

1. Create a Fabric instance with Iris, for example with `cargo run --example smoke -- <dir> 1.21.1 --fabric --mod=iris --orrery-shaders --launch --wait=1500`.
2. Link the repository folder into the instance: `mklink /J <game dir>\shaderpacks\Orrery-Dev <repo>\shaderpack` on Windows or `ln -s` elsewhere.
3. Select `Orrery-Dev` in the Iris menu (`O`) and press `R` after every change. Compile errors appear in the chat and in `logs/latest.log`.
4. `cargo test -p orrery-core shaderpack` checks the structure, includes, options and translations. `cargo run --example shader_check` compiles every program with `glslangValidator`. CI runs it on Linux.

Raise `SHADERPACK_VERSION` in `crates/orrery-core/src/shaderpack.rs` when a release changes the pack, so the file name changes with it.
