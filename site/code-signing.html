Code signing policy

Status: Orrery applies for free code signing for open-source projects through the SignPath Foundation. Until the application is accepted, the Windows installers are not signed, and Windows SmartScreen may warn before the first start.

What gets signed

Only the Windows files of official releases: the launcher executable orrery.exe, the setup program and the MSI package. They are built by the public release workflow on GitHub-hosted runners from a tagged commit of the public repository. Nothing is built or signed on a private machine. Every file carries the product name Orrery and its version in its metadata.

Updates are additionally signed with Orrery's own updater key. The launcher only installs an update whose updater signature matches.

Team roles

  • Committers and reviewers: the members of the nowaaak/orrery repository
  • Approvers: the repository owner, nowaaak

Every release is approved by hand before it is signed. All accounts with access use multi-factor authentication.

Privacy

Orrery only contacts the services it needs to install and start Minecraft, such as Mojang, Microsoft, Modrinth and the mod loader repositories. It has no server of its own, no telemetry and no ads. The privacy page lists every service and what it receives.

Reporting a problem

If you think a signed file is malicious or was not built from this repository, please open an issue.
