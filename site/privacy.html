Privacy

Last updated: 6 November 2026

Orrery is a desktop application that runs on your computer. It has no server, no user database, no analytics and no telemetry. The developer does not receive any data about you or about how you use Orrery.

Data stored on your computer

  • Microsoft sign-in. After you sign in, Orrery stores the Microsoft refresh token in the system keychain (Windows Credential Manager, macOS Keychain or the Secret Service on Linux). The short-lived Minecraft access token is kept in memory only while Orrery runs and is never written to disk. Every game start signs in again online. Removing the account deletes the refresh token.
  • Account list. Player name, player UUID and skin details of the accounts you added, in Orrery's settings folder.
  • Game data. Instances, worlds, mods, screenshots, logs, playtime and launcher settings in Orrery's data folder.

Removing an account in Orrery deletes its stored sign-in. Uninstalling Orrery and deleting its data folder removes everything else.

Services Orrery connects to

Orrery only contacts the following services, and only for the purpose listed. Each service handles requests under its own privacy policy.

Service Purpose What is sent
Microsoft identity platform, Xbox Live, Minecraft services Sign-in, checking game ownership, starting the game, skins and capes The tokens of the sign-in you started, and skins you choose to upload
Mojang (piston-meta, libraries, resources, session server) Game versions, game files, Java runtimes, looking up player skins Standard download requests, player names you look up
Fabric, Legacy Fabric and Quilt meta and Maven servers Mod loader versions and files Standard download requests
NeoForged Maven (maven.neoforged.net) NeoForge versions, its installer and libraries Standard download requests
Forge Maven (maven.minecraftforge.net) Forge versions, its installer and libraries Standard download requests
Modrinth Searching and installing mods, packs and modpacks Your search terms, the selected Minecraft version and loader, and hashes of installed files to find updates
CurseForge (api.curseforge.com, forgecdn.net) Searching and installing mods, packs and modpacks, only in builds with a CurseForge API key Your search terms, the selected Minecraft version and loader, the ids of installed projects for updates, and fingerprints of files when you export a CurseForge modpack
Eclipse Adoptium Java runtime when Mojang has none for your system Your operating system and architecture
GitHub Checking for and downloading Orrery updates Standard download requests
mclo.gs Sharing a game log, only when you press Share and confirm the preview The log text with access tokens, IP addresses, user names and home folder paths removed
Minecraft servers in your server list Showing status, player count and ping A standard server list ping

Like every network request, these requests carry your IP address. Orrery identifies itself with a user agent that names Orrery, its version and its source code repository.

Local connections

Discord Rich Presence talks only to the Discord app on your own computer and can be switched off in the settings. The optional Orrery Companion mod connects to the launcher over 127.0.0.1 and never leaves your computer.

Children

Orrery follows the restrictions Microsoft and Xbox apply to child accounts. It does not collect data from anyone.
